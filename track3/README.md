# Track 3: Backend Server

## What this track does
Serves the finished satellite and analysis data to the website over HTTP, using FastAPI. It provides the city list, per-city results (metadata and statistics), map layer images, and validation of user-drawn areas.

## How to run
From inside the `track3` folder:

```
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

Then open `http://localhost:8000/docs`.

## Where the endpoints are documented
See `API.md` in this folder, or the auto-generated page at `/docs` while the server runs.

## The Week 2 switch
In `main.py`, change this one line:

```
DATA_ROOT = Path("stub_data")
```

to:

```
DATA_ROOT = Path("../data")
```

That is the entire integration with the real output from Tracks 1 and 2.

## Known limitations
- Serves hand-written stub data for Bhubaneswar only.
- Layer images are placeholders generated by `make_stub_images.py`.
- CORS allows all origins, which is fine for development but should be tightened for production.
- Results are cached in memory, so the server must be restarted after a `meta.json` changes.
